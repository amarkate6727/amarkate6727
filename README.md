## Featured project

### Medical RAG Chatbot
> End-to-end RAG pipeline for medical document question answering.

**Architecture:**
PDF ingestion (LangChain) → text chunking (500 char, 50 overlap) → sentence-transformers embeddings → FAISS vector store → flan-t5 LLM inference → FastAPI REST API with multi-session conversation memory → HTML/JS web UI

**Design principle:** Zero-hallucination — model explicitly declines when the answer is not in the retrieved context. Never generates from LLM training memory.

[View repository](https://github.com/amarkate6727/rag-medical)
